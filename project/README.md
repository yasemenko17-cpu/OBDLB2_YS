# Наскрізний проєкт: розгортання і дані

Ця тека продовжує проєкт із OBDZ-LAB01. Скопіюйте сюди з LAB01 файли `er_model.json`, `schema.sql`, `data_dictionary.md`, а потім додайте:

- `migrations/V001__schema.sql`, `V002__...sql`, `V003__...sql`: версіоновані скрипти зміни схеми (перша міграція це ваш `schema.sql`);
- `data/<таблиця>.csv`: дані кожної таблиці з рядком заголовка;
- `make_data.py`: скрипт, що відтворює CSV (фіксоване зерно генератора);
- `load.psql`: команди `\copy` у порядку завантаження;
- `post_load.sql`: вирівнювання послідовностей після завантаження;
- `integrity_checks.sql`: запити, що знаходять порушення цілісності (порожній результат означає, що все гаразд).

Розгорнути проєкт у схемі `project` вашої бази: `python project_check/deploy_project.py`.
Перевірити: `pytest project_check` (потрібен запущений PostgreSQL). Кожну міграцію й набір даних фіксуйте окремим комітом.
